---
id: kerning
nombre: Kerning
definicion: Ajuste del espacio entre dos caracteres concretos para equilibrar ópticamente su separación.
categoria: tipografia
nivel: intermedio
sinonimos: [interletraje de pares]
consultas:
  - espacio entre dos letras
  - ajustar separación de letras concretas
etiquetas: [tipografia]
relaciones:
  - { tipo: se_confunde_con, destino: tracking }
  - { tipo: relacionado_con, destino: interlineado }
ejemplos:
  - Pares como "AV" o "To" suelen necesitar kerning para no verse separados.
---
El **kerning** actúa entre pares de letras. No cambia el espaciado global, solo corrige combinaciones concretas que se ven mal.
  - diferencia entre kerning y tracking
